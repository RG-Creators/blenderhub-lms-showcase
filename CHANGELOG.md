# Changelog — BlenderHub LMS & 3D Asset Marketplace

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-11-22
### Added
- Complete LMS video course delivery pipeline with hierarchical topics and subtopics.
- 3D Digital Asset marketplace with multi-format download pipelines (FBX, OBJ, BLEND, GLTF).
- Creator Economy portal with verification workflow, asset approval queue, and payout ledger.
- Custom 3D Model request system with competitive creator bidding (`model_requests` and `model_bids`).
- Multi-channel SharePay OTP verification for transaction integrity.
- Automated GitHub Actions showcase documentation synchronization pipeline.
